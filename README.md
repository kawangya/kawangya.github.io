# 主域名入口仓库

这个仓库是个人域名的主入口，同时承载个人内容分享。主页面自动跳转到目标站点，其他内容则以文件夹形式存放供访问。

## 项目用途

该仓库的核心作用是：

- 作为主域名的统一入口
- 让一级域名作为中转页，自动引导到主要目标站点
- 同时为个人内容分享和资源存放提供存储空间
- 便于整合个人作品、工具、文档等多类内容

## 目录说明

- `index.html`：主页面入口，负责自动跳转到目标地址（<https://kawangya.github.io/kw-nav/>）
- `fullbackup/`：个人内容分享区，存放各类资源文件
- `README.md`：项目说明文档
- `LICENSE`：开源协议文件

## 跳转原理

该页面通过两种方式实现跳转：

1. 使用 `<meta http-equiv="refresh">` 进行自动刷新跳转
2. 使用 JavaScript 的 `window.location.replace()` 兜底跳转

这样可以在大多数浏览器中都能稳定跳转到目标站点。

## 使用方式

1. 克隆或 Fork 本仓库
2. 修改 `index.html` 中的目标链接
3. 将代码推送到 GitHub
4. 在 GitHub Pages 中启用该仓库
5. 访问主域名即可自动跳转到目标页面

## 适用场景

- 主域名作为入口站点
- 子项目/子站点的统一跳转入口
- 个人主页与导航页分离场景
- 需要保留稳定域名但切换实际内容位置时

## 维护建议

- 目标地址应保持稳定，避免频繁变更
- 如果站点迁移，直接更新 `index.html` 中的跳转链接即可
- 若后续增加多个入口，可在中转页上保留更多跳转入口

## 说明

这个仓库用作个人域名的主入口，既提供了自动中转功能，也为个人内容分享提供了便利的存储位置。根目录下的 index.html 负责流量入口的导向，而其他文件夹则保留了个人资源的访问路径。

这种设计既适合作为 GitHub Pages 的主域名入口，也支持长期累积个人内容分享，是主页面与资源库相结合的实用方案。
