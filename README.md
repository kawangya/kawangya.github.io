# 主域名中转仓库

这个仓库用于承载主域名入口，并在访问时自动跳转到目标站点，适合用作 GitHub Pages 的主域名中转页。

例如，当前仓库会直接将访问者引导到：

- https://kawangya.github.io/kw-nav/

## 项目用途

该仓库的核心作用是：

- 提供统一的主域名入口
- 让一级域名作为中转页，避免直接暴露复杂子目录结构
- 便于后续站点迁移或调整目标地址
- 适合导航页、文档站、个人站点入口聚合等场景

## 目录说明

- `index.html`：主页面入口，负责自动跳转到目标地址
- `README.md`：项目说明文档

## 跳转原理

该页面通过两种方式实现跳转：

1. 使用 `<meta http-equiv="refresh">` 进行自动刷新跳转
2. 使用 JavaScript 的 `window.location.replace()` 兜底跳转

这样可以在大多数浏览器中都能稳定跳转到目标站点。

## 使用方式

1. 克隆或 Fork 本仓库
2. 修改 `index.html` 中的目标链接
3. 将代码推送到 GitHub
4. 在 GitHub Pages 中启用该仓库
5. 访问主域名即可自动跳转到目标页面

## 适用场景

- 主域名作为入口站点
- 子项目/子站点的统一跳转入口
- 个人主页与导航页分离场景
- 需要保留稳定域名但切换实际内容位置时

## 维护建议

- 目标地址应保持稳定，避免频繁变更
- 如果站点迁移，直接更新 `index.html` 中的跳转链接即可
- 若后续增加多个入口，可在中转页上保留更多跳转入口

## 说明

这个仓库本身不承载复杂业务内容，而是用于“主域名入口中转”的职责。它非常适合 GitHub Pages 等静态站点场景，用来统一流量入口并提高整体站点的可维护性。
